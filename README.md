## 温度机制

- 温度 = 天气基础值 + 场上所有火焰塔和三叉戟塔的等级之和 - 场上所有冰塔的等级之和
- 建造火焰/三叉戟/TNT塔：温度 + 1
- 升级火焰/三叉戟/TNT塔：温度 + 1
- 拆除火焰/三叉戟/TNT塔：温度 - 被拆除塔的等级
- 建造冰塔：温度 - 1
- 升级冰塔：温度 - 1
- 拆除冰塔：温度 + 被拆除塔的等级
- 燃烧伤害 = 当前温度（温度 ≤ 0 时无法点燃敌人）
- 冻结时长 = 基础冻结时长 × (1 + |温度|/100)（温度 < 0 时生效）

## 操作说明

- 鼠标点击空地建造选中的炮塔
- 点击已有炮塔选中，显示详细信息
- `0`~`9` 选择炮塔类型
- `U` 升级选中炮塔
- `S` 出售选中炮塔
- `R` 切换分支
- `ESC` 暂停游戏
