# 像素防线 · 晶域守卫

基于 Pygame + Python 实现的塔防游戏。

## 炮塔一览

| 按键 | 名称 | 造价 | 定位 |
|------|------|------|------|
| 1 | 箭塔 | 100 | 基础物理输出，Lv6金币加成，Lv11破甲 |
| 2 | 金矿 | 50 | 被动金币产量，Lv6每波额外产出，Lv11利息 |
| 3 | 冰塔 | 150 | 减速 + 冻结控制，Lv11 群控+对冻结敌人额外伤害 |
| 4 | 传送塔 | 300 | 瞬移回起点，Lv6概率秒杀，Lv11百分比伤害 |
| 5 | 火塔 | 200 | 燃烧 + 击晕，Lv11龙息 |
| 6 | 三叉戟塔 | 400 | 整列闪电 + 燃烧，Lv6金币加成，Lv11十字闪电 |
| 7 | 风塔 | 250 | 击退 + 输出，lv6蓄风，lv11距离增伤+击晕 |
| 8 | 毒塔 | 175 | 中毒，lv6群伤，Lv11叠层*4 |

所有炮塔最高 15 级，Lv6 / Lv11 为进化节点。

## 天气系统

每波开始时随机切换天气，影响温度和战斗：

| 天气 | 温度 | 效果 |
|------|------|------|
| 酷暑 | 40 | 火焰伤害大幅提升 |
| 晴天 | 30 | 无特殊效果 |
| 多云 | 20 | 温度较低 |
| 雨天 | 10 | 敌人减速50%，无法点燃 |
| 雪天 | 0 | 冻结时间延长50% |
| 雷暴 | 15 | 周期性闪电劈击，无法点燃，减速50% |
| 酸雨 | 5 | 炮塔等级-1，敌人中毒，无法点燃，减速50%，毒层*2 |
| 顺风 | 25 | 敌人加速50%，射程+50% |
| 逆风 | 25 | 敌人减速50%，射程-50% |
| 烈日 | 50 | 敌人持续燃烧 |
| 迷雾 | 15 | 视野遮挡 |
| 极寒 | -20 | 敌人减速50%，无法点燃，冻结时间延长100% |
| 磁暴 | 20 | 瞬移失效，闪电伤害*2，金属敌人破甲 |
| 极光 | -10 | ? |
| 火雨 | 100 | 敌人持续燃烧，无法冻结 |
| 彩虹 | 15 | 双方全属性提高 |

天气可花费金币通过天气预报预测。

## 温度机制

- 温度 = 天气基础值 + 场上所有火焰塔和三叉戟塔的等级之和
- 建造火焰/三叉戟塔：温度 + 1
- 升级火焰/三叉戟塔：温度 + 1
- 拆除火焰/三叉戟塔：温度 - 被拆除塔的等级
- 燃烧伤害 = 当前温度


## 操作说明

- 鼠标点击空地建造选中的炮塔
- 点击已有炮塔选中，显示详细信息
- `1`~`6` 选择炮塔类型
- `U` 升级选中炮塔
- `S` 出售选中炮塔
- `P` 暂停游戏
- `ESC` 取消选择
- `F11` 切换全屏
