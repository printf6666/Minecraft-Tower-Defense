# 像素防线 · 晶域守卫

基于 Pygame 实现的塔防游戏。

## 玩法简介

在随机生成的地图上建造炮塔，抵御一波波敌人的进攻。合理搭配炮塔类型、利用天气变化、控制战场温度，守住 40 波即可获胜。

## 炮塔一览

| 按键 | 名称 | 造价 | 定位 |
|------|------|------|------|
| 1 | 箭塔 | 100 | 基础物理输出，Lv6 起金币加成，Lv11 破甲 |
| 2 | 金矿 | 50 | 被动金币产量，Lv6 每波额外产出，Lv11 利息 |
| 3 | 寒冰塔 | 150 | 减速 + 冻结控制，Lv11 对冻结敌人额外伤害 |
| 4 | 传送塔 | 300 | 瞬移回起点，Lv6 概率秒杀，Lv11 斩杀线 |
| 5 | 火焰塔 | 200 | 燃烧 + 击晕，Lv11 龙息池持续灼烧 |
| 6 | 三叉戟塔 | 400 | 整列闪电 + 燃烧，Lv6 金币加成，Lv11 雨天翻倍 |

所有炮塔最高 15 级，Lv6 / Lv11 为进化节点。

## 天气系统

每波开始时随机切换天气，影响温度和战斗：

| 天气 | 温度 | 效果 |
|------|------|------|
| 酷暑 | 40 | 火焰伤害大幅提升 |
| 晴天 | 30 | 无特殊效果 |
| 多云 | 20 | 温度较低 |
| 雨天 | 10 | 敌人减速 50%，无法点燃，有雨滴动画 |
| 雪天 | 0 | 冻结时间延长 0.2s，有雪花动画 |
| 雷暴 | 15 | 周期性闪电劈击，无法点燃，减速 50%，有雨滴动画 |
| 酸雨 | 5 | 全部炮塔等级 -1，敌人永久中毒，无法点燃，减速 50% |

## 温度机制

- 温度 = 天气基础值 + 场上所有火焰塔和三叉戟塔的等级之和
- 建造火焰/三叉戟塔：温度 +1
- 升级火焰/三叉戟塔：温度 +1
- 拆除火焰/三叉戟塔：温度 -被拆除塔的等级
- 火焰塔燃烧伤害 = 当前温度

## 状态效果

| 图标 | 效果 |
|------|------|
| burn | 燃烧：每 0.5s 受到温度等值的伤害 |
| freeze | 冻结：无法移动，雪天延长 0.2s |
| slow | 减速：移速降为 50% |
| stun | 击晕：无法行动 |
| broken | 破甲：受伤永久增加 20% |
| poison | 中毒：每 1.25s 受到 30 点伤害 |

雨天/雷暴/酸雨下敌人自带 slow；酸雨下敌人自带 poison；雨天/雷暴/酸雨下敌人无法被点燃。

## 操作说明

- 鼠标点击空地建造选中的炮塔
- 点击已有炮塔选中，显示详细信息
- `1`~`6` 选择炮塔类型
- `U` 升级选中炮塔
- `S` 出售选中炮塔
- `ESC` 取消选择
- `F11` 切换全屏

## 运行方式

```bash
pip install pygame
python main.py
```

## 打包

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --add-data "tower;tower" --add-data "debuff;debuff" --add-data "enemy;enemy" --add-data "bgm;bgm" --name "MCTD" main.py
```
