# 第 100 波最终 BOSS 设计案：终焉·奥米伽（OMEGA）

> 一句话：第 50 波的 Herobrine 是「沿着路线走来的传说」；
> 第 100 波的奥米伽是「写下这个传说的那条命令」。
> 它没有腿，不走路。它漂浮、瞬移、冲刺，然后一条一条地删除你的世界。

---

## 1. 需求对照

| 需求 | 方案 |
|------|------|
| 与第 50 波 Herobrine 不同，不按路线走 | BOSS 不属于路径系统：`FinalBoss` 重写 `update()`，不读 `path`，在整张战场上空自由悬停 / 冲刺 / 瞬移（参考猪龙鱼公爵、光之女皇、石巨人的“场地型”战斗） |
| 站桩型、屏幕中自由移动 | 8 个随机落点 + 向炮塔集群施压的落点选择；P1 缓慢漂浮，P2 开始冲刺，P3 加入瞬移，P4 高速冲刺 + 瞬移混合 |
| 一共 100 层血 | `FINAL_BOSS_LAYERS = 100`，每击破一层立即回满下一层，层数直接显示在顶部血条上 |
| 每层 2 亿 | `FINAL_BOSS_LAYER_HEALTH = 200_000_000` |
| 总血量 | 100 × 200,000,000 = **20,000,000,000（200 亿）** |
| 体型放大 50% | 核心从 256×256 提高到 384×384（3×3 格），所有符文环 / 碎片 / 光晕同步放大 |
| 余烬陨石打 5 层 | `take_damage(..., layers=5)`，陨石一次击穿 5 层，不按当前层剩余血量结算 |
| 新增酸雨技能 | `/weather acid_rain`：全场炮塔 -1 级；护盾可挡；蜜脾附魔时反而召唤蜂群反扑 BOSS |

### 数值核对

```
100 层 × 200,000,000 = 20,000,000,000（200 亿）
```

三个要求现在完全自洽，不需要任何折中。

## 2. 背景故事

第 50 波，你打碎了 Herobrine 的 18 层外壳，以为自己赢了。

但 Herobrine 从来不是「神」，它只是代码里的一段传言：一个被玩家反复讲述、最终被世界信以为真的鬼故事。

第 100 波，世界的地基终于承受不住这个传言了。在地图最深处，那条从未被执行、也从未被删除的**第一条命令**醒了过来：

> `/> 检测到世界完整性崩溃。`
> `/> 执行最终指令。`

它给自己取名 **奥米伽（OMEGA）**——最后一条命令。
它把 Herobrine 的残骸拆开重写，编成 **100 层**外壳：每 25 层一段，四段拼成一条完整的命令。
每打碎一层，就有一段 Herobrine 的代码被永久删除。

## 4. 战斗结构：4 阶段 × 25 层

| 阶段 | 层数 | 名称 | 移动方式 | 技能池 | 定位 |
|------|------|------|----------|--------|------|
| I | 100 → 76 | **编译 COMPILE** | 缓慢漂浮，落点温和 | 召唤 / 填充 / 执行 | 教学：让玩家读懂三种读条 |
| II | 75 → 51 | **覆写 OVERWRITE** | 45% 概率冲刺 | + 抹除线 / 相移 / 酸雨 | 开始拆防线，要求铺盾或蜜脾 |
| III | 50 → 26 | **执行 EXECUTE** | 冲刺 + 瞬移 | + 时停 / 规则覆写 | 多线压力，考验恢复能力 |
| IV | 25 → 1 | **终焉 OMEGA** | 高速冲刺 + 瞬移混合 | + 世界重载 | 终局 DPS 检定 |

> 酸雨从第 2 阶段开始进入技能池，且自带 15 秒独立冷却（`acid_cooldown`），
> 不会连续两发把整条防线洗没。第 1 阶段不会出现酸雨。

阶段切换时：

* BOSS 获得 **1.5 秒无敌**并瞬移到新落点；
* 全场爆出 24 枚指令碎片，屏幕闪白；
* 顶部播报 `阶段 N · XXX`；
* 技能冷却缩短。

每击破 **6 层**，BOSS 立刻追加释放一次指令——防止玩家在爆发窗口里完全无压力输出。

## 5. 移动 AI：不走路，但每一秒都在选位置

BOSS 不参与寻路。它只在像素空间里维护一个「锚点」：

```text
每 2.5s（P1）/ 2.0s（P2）/ 1.6s（P3）/ 1.25s（P4）重新选点：
   55% 概率选在玩家炮塔最密集的区域上方（施加压力）
   45% 概率选在场地内的随机点（给玩家喘息）
```

三种移动方式：

1. **悬停（Hover）**：以 1.5~2.5 px/帧漂向锚点，同时上下正弦浮动 12px。
2. **冲刺（Dash）**：先锁定目标点，以 17~25 px/帧直线冲过去，身后留下残影；
   冲刺路径 1 格内的炮塔会被 **锁定 1.5 秒**（不会摧毁）。
3. **瞬移（Teleport）**：原地与落点各炸开一圈紫色冲击波，落点 2 格内的炮塔被 **锁定 1.7 秒**。

活动范围被限制在 `x∈[280, 1768]`、`y∈[300, 1148]`，保证它始终在战场上方、不会压到右侧信息栏。

> 设计目的：玩家的防线是静态的，BOSS 的动态位置本身就是信息——
> 它往哪飞，下一波压力就在哪。玩家需要决定「补塔」还是「补盾」。

## 6. 技能表

所有技能都以 Minecraft 指令命名，并通过顶部播报条喊出指令原文。

### 6.1 指令·召唤 `/summon`

| 项目 | 内容 |
|------|------|
| 预警 | 无（传送门出现即预警） |
| 效果 | 在路径前中段打开 3 / 4 / 5 / 6 道虚空传送门，延迟 0.4~1.0 秒后爬出小怪 |
| 小怪池 | P1 僵尸/骷髅/苦力怕；P2 合金甲/苦力怕；P3+ 幻翼/凋灵/合金甲 |
| 血量 | 固定值（40M~150M × 阶段加成），**不套用 1.2^波数**，否则第 100 波小怪会比 BOSS 还肉 |
| 破解 | 单体高伤塔 + 秒杀塔；漏怪会直接导致游戏结束 |

### 6.2 指令·填充 `/fill`

| 项目 | 内容 |
|------|------|
| 预警 | 红色的命令方块落在目标炮塔头顶，闪烁 2.5 秒 |
| 效果 | 方块爆炸，**只摧毁脚下这一格**（radius=0），2/3/4/5 个目标 |
| 破解 | 护盾可以挡一发；脉冲护盾期间免疫 |

### 6.3 指令·执行 `/execute`

| 项目 | 内容 |
|------|------|
| 预警 | 炮塔头顶出现红色符文圈 + 倒计时 2.5 秒 |
| 效果 | 金色落雷劈下；命中后该炮塔被 **锁定 12 秒**（头顶出现紫色 ✖） |
| 破解 | 护盾先破盾；脉冲护盾免疫；被锁定的塔可以通过继续输出保护其他塔 |

> 这是「持续压力」而不是「永久损失」——真正会永久删塔的是抹除线与世界重载。

### 6.4 指令·抹除 `/kill @e[type=tower]`

| 项目 | 内容 |
|------|------|
| 预警 | 一条贯穿全图的红色删除线，闪烁 1.5 秒（自动瞄准炮塔最多的行/列） |
| 效果 | 线上最多 **永久删除 3 座**炮塔，其余被锁定 8 秒；护盾可以各挡一次 |
| 破解 | 提前给关键塔上盾；把塔分散摆放，别让一条线串起全部主力 |

### 6.5 指令·相移 `/tp`

| 项目 | 内容 |
|------|------|
| 效果 | 立即瞬移到新落点，双端冲击波，落点附近炮塔锁定 1.7 秒 |
| 破解 | 无直接伤害，但会打乱集火；配合冲刺形成「贴脸拆塔」压迫 |

### 6.6 指令·时停 `/tick freeze`

| 项目 | 内容 |
|------|------|
| 预警 | 顶部播报 + 全屏蓝色滤镜 + `TICK FREEZE` |
| 效果 | **全场炮塔停止攻击 3 秒**，BOSS 同时爆出 18 枚指令碎片 |
| 破解 | 时停不阻止护盾/产金；把它当成免费的 3 秒，准备迎接下一轮 |

### 6.7 指令·覆写 `/gamerule`

| 项目 | 内容 |
|------|------|
| 效果 | 随机一条世界规则，持续 12 秒：`攻速-50%` / `射程-30%` / `金币产量归零` |
| 破解 | 三条都是软压制，不会直接毁塔；雷达图右侧会显示剩余时间 |

### 6.8 指令·酸雨 `/weather acid_rain`（第 2 阶段起）

| 项目 | 内容 |
|------|------|
| 预警 | 全屏绿色酸雨滤镜 + `ACID RAIN` + 酸雨粒子从屏幕上方倾泻 |
| 效果 | **场上所有炮塔等级 -1**；护盾塔先碎盾、等级不变；脉冲护盾免疫 |
| 频率 | 独立 15 秒冷却（`acid_cooldown`），不会连续释放 |
| 破解 | ① 护盾抵挡；② **蜜脾附魔**：酸雨完全不生效，既不破盾也不降级；改为触发和普通酸雨天气完全相同的「蜂群」效果——**从终点向地图内扇形召唤 10 波、每波 5 只（共 50 只）蜜蜂**，每只造成目标 10% 最大生命的无视护甲伤害。50 × 20M = 10 亿，正好 5 层 |
| 设计意图 | 把「蜜脾」从一个冷门附魔变成终局关键解；没有蜜脾的玩家必须靠护盾和补建硬扛 |

### 6.9 终焉·世界重载 `/reload`（第 4 阶段专属）

| 项目 | 内容 |
|------|------|
| 预警 | 全屏红色充能环，读条 **12 秒**，顶部显示剩余秒数 |
| 效果 | 读条结束时，**所有没有护盾的炮塔被从代码中抹除**；有护盾的只碎盾 |
| 破解 | 12 秒内**击破任意一层血**即可打断：打断后 BOSS 硬直 3 秒、本次重载取消 |
| 破绽 | 咏唱期间 BOSS 站在原地不动，且受到 **1.5 倍伤害**——这是全战最大的输出窗口 |

> 这是整场战斗的高潮：一次必须用 DPS 回应的「团灭读条」。

### 6.10 被动

| 被动 | 说明 |
|------|------|
| **层甲** | 100 层，每层独立血条；单次伤害最多打穿一层，溢出伤害丢弃（陨石除外，见下） |
| **免疫** | 冰冻、眩晕、减速、击退、传送全部无效；**燃烧、中毒、凋零有效**（DoT 可以磨层） |
| **层爆** | 每破一层：冲击波 + 闪屏；每 6 层额外释放一次指令 |
| **转阶段** | 1.5 秒无敌 + 瞬移 + 全屏碎片 |
| **接触锁定** | 冲刺时压过的炮塔锁定 1.5 秒 |
| **死亡演出** | 4 秒爆炸演出，期间清空所有未结算指令、秒杀自己召唤的全部小怪 |
| **陨石弱点** | 余烬重生的陨石（1,000,000,007）一次打穿 **5 层**，无视当前层剩余血量 |

## 8. 与现有系统的交互

| 系统 | 交互 |
|------|------|
| 寻路 / 冰墙 | BOSS 完全忽略；冰墙只挡小怪 |
| 护盾塔 / 脉冲护盾 | 护盾挡一次删除（碎盾），脉冲期间完全免疫 |
| 燃烧 / 中毒 / 凋零 | 正常结算，是「磨层」的稳定手段 |
| 冰冻 / 眩晕 / 减速 / 击退 | 免疫（否则 BOSS 会被永久控在原地） |
| 传送塔瞬移 | `teleport_to_start()` 对 BOSS 为空操作 |
| 地狱射线（物理 Lv11 分支3） | 对 BOSS 改为 5% 当前层血量，避免 99,999,999 直接超模 |
| 余烬重生陨石 | 通过 `layers=5` 参数一次击穿 5 层，并正常触发阶段切换/世界重载打断 |
| 蜜脾附魔 | 酸雨技能完全免疫，并触发与普通酸雨一致的「终点 10 波蜂群」反打 BOSS |
| 不稳定水晶 | 核弹爆炸保底生成 1 颗；仅敌怪接触引爆；同格不重复生成；128×128 带脉冲描边 |
| 永夜天气 | 第 50 / 100 波强制永夜；**读档、调试跳波也走 `force_boss_weather()` 兜底**（修复了读档进入 100 波却是逆风的问题）；BOSS 战期间关闭黑暗遮罩保证弹幕可读 |
| 永夜回血 | 不会给 BOSS 回血（否则死亡演出中的 BOSS 会被“复活”） |
| 存档 | 进入第 100 波时照常存档；读档后从第 100 波重新开始 BOSS 战 |
| 总波数 | `total_waves` 从 99 改为 100，击杀 BOSS 后进入胜利结算 |

## 10. 玩家攻略（设计意图）

1. **前 25 层（编译）**：读懂三种读条。优先铺满「单体高伤 + 秒杀」塔，护盾塔至少 1 座。
2. **26~50 层（覆写）**：开始出现删除线。把主力塔拆成 2~3 个集群，避免一条线串完；护盾塔升级到 Lv11 全图上盾。
3. **51~75 层（执行）**：时停会打断输出节奏；酸雨会把整条防线等级 -1。留好核弹/秒杀塔的冷却，在时停结束瞬间爆发。
4. **最后 25 层（终焉）**：世界重载是唯一会「直接输掉」的技能。看到读条后把全部爆发砸上去——12 秒打穿一层即可打断；打不穿就提前给所有塔上盾。
5. **经济**：BOSS 不走路，所以小怪是唯一的漏怪来源；不要在终局把金币全砸在清怪上，留钱补被删掉/被酸雨降级的塔。
6. **蜜脾是版本答案**：有蜜脾时酸雨不但不掉级，还会从终点召来 10 波蜂群（共 50 只，约 5 层伤害）；没有蜜脾就多铺盾塔，酸雨每次只碎盾不降级。

### 快速预览第 100 波

正式流程要从第 1 波打到第 100 波。想立刻看 BOSS，可以临时在 `game.py` 的 `Game.start_game()` 末尾加一行：

```python
self.wave_manager.current_wave = 99
```

再启动游戏就会直接进入第 100 波（永夜 + 终焉·奥米伽）。看完删掉这行即可。
